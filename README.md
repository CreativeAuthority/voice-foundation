# Voice Foundation

By [Creative Authority](https://agentslearnai.com).

Most AI writing sounds like every other agent because it was trained on every other agent. Voice Foundation fixes that at the source. It runs two guided conversations that capture how you think, how you decide, and how you actually sound, then writes that into a foundation your AI reads every time it drafts something with your name on it.

## What you get

- `voice_foundation.md`, your foundation: mission, decision rules, hard boundaries, and your written and spoken voice, in your own words.
- A branded PDF with a portable operating prompt you can paste into any AI, inside this system or out.
- `write in my voice`, a drafting skill for listing descriptions, marketing copy, and client email that refuses to run on a generic register.

## Requirements

Claude Pro or Max, the Claude desktop app, and a folder connected to your session. Your foundation is saved to that folder and it is yours.

## Install

In the Claude desktop app, open Customize, then Plugins, then Add marketplace, and enter:

```
CreativeAuthority/voice-foundation
```

Install Voice Foundation from the list, then start a session and say:

```
run my voice foundation
```

Each conversation takes thirty to forty-five minutes. You can stop and pick it up later.

## After it is built

Say `write in my voice` and give it a piece to draft. It reads your foundation, asks what only you know about the property or the situation, drafts it, checks the result against your own list of AI tells, and rewrites anything that trips one.
