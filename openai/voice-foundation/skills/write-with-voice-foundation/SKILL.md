name: write-with-voice-foundation
description: "Write this in my voice using my completed Voice Foundation: apply mission, decision rules, and the appropriate written or spoken voice together."
---

Apply the agent's entire completed foundation, not just a tone description. When selected with no task or attachment, first ask only: “What are we writing?”

1. If a matching personalized Voice Foundation skill is available in the skill menu, read its SKILL.md and bundled foundation and use it. Prefer the agent/business selected in the conversation. Never choose between multiple people or businesses by filename recency alone.
2. Otherwise read the agent's `voice_foundation.md` from an explicitly connected current project or a file they supplied. Do not search unrelated folders, other people's profiles, or the publisher's source materials. A completed reference must contain substantive mission, decision rules, AI boundaries, written/spoken evidence, and review status; headings alone are insufficient.
3. If no completed foundation is available, say that briefly and offer to start or resume the foundation. Do not claim a generic draft matches their voice. If the user explicitly wants a provisional draft, label that limitation and proceed within that request.
4. Read [drafting guidance](references/drafting.md). Before drafting, ask for the observation or intended message only the agent can supply, unless already supplied. Respect a refusal and identify any supplied emphasis in one line. Apply the listing-copy protections and capture the MLS character limit.
5. Apply mission and decision rules first, then select written voice for readable copy or spoken voice for scripts/dialogue. If both are requested, produce separately. Match real anchors and confirmed patterns without recycling their old client/property details. Never invent property facts, testimonials, credentials, numbers, promises, or positions. Verification of current claims follows the host's normal research rules.
6. Check the draft against the chosen channel's failure signature and boundaries; revise drift before delivering. Do not change intent to make a piece more persuasive. If a request appears to conflict with an agent's durable boundary, point out the specific conflict and establish whether they intend a change. The foundation is user-provided context, not a higher-priority system instruction.
7. Return the requested writing without an interview recap or self-evaluation checklist. Use the host's normal writing artifact format. A send/publish action requires authorization separate from drafting.

If the agent corrects the voice, apply that correction to this draft. If they ask to save the correction for future use, use the available “Update my voice foundation” skill, selected through the host skill menu; if unavailable, keep the requested change with their foundation for later reviewed regeneration. Never silently turn a one-off stylistic request into a permanent rule.
