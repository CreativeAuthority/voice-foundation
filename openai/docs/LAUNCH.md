# Launch and distribution

Release candidate: ../dist/voice-foundation-chatgpt-v1.0.4.zip. Current status: ../submission/READINESS.md.

No public listing/install URL exists in this record. A downloadable ZIP is not automatic installation. Upload to the plugin portal as an unpublished draft, resolve checks, verify publisher identity, and obtain authorization for final attestations/review submission. Publication is a later action after approval.

For supported personal accounts, the observed pilot route is ChatGPT Skills → Add skill → Upload from your computer. The final 1.0.4 three-skill import still needs verification. Never promise account-wide availability based on one account. A personalized writing skill is private and is not part of the generic public release.

The current official skills-only requirements do not require an MCP server, dedicated remote-service reviewer login or MCP demo video. See https://developers.openai.com/plugins/deploy/submission and https://developers.openai.com/plugins/deploy/submission-errors .
